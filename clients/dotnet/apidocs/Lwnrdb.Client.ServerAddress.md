The host and client port of one server.

## DefaultPort
The server's default client port, `8989`.

## ServerAddress(string, int)
Creates an address.

@param host the host name or IP address; not blank
@param port the client port from 1 to 65535; `8989` by default
@exception System.ArgumentException when the host is blank
@exception System.ArgumentOutOfRangeException when the port is outside 1 to 65535

## Host
The host name or IP address.

## Port
The client port.

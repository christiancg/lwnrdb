# UserInfo

One user, as `Users.list` returns it.

## username

The username.

## admin

Whether the user is an admin.

## globalPermissions

Server-wide grants.

## databasePermissions

Grants by database.

## collectionPermissions

Grants by `database|collection`.

## scriptPermissions

Script grants by database.

## ownedDatabases

The databases the user owns.

## raw

The row as the server sent it.

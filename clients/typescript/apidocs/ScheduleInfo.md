# ScheduleInfo

A schedule, as `Schedules.list` returns it.

## name

Its name.

## procedureName

The procedure it calls.

## cron

Its cron expression.

## intervalMs

Its interval in milliseconds.

## enabled

Whether it runs.

## version

Its version.

## definer

The user it runs as.

## nextRunAt

When it runs next, in epoch milliseconds.

## raw

The row as the server sent it.

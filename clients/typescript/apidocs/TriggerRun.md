# TriggerRun

A trigger run that is pending or exhausted its attempts.

## runId

Its id.

## status

`PENDING`, `DEAD` or `STAGED`.

## database

Its database.

## collection

Its collection.

## trigger

The trigger.

## procedure

The procedure it calls.

## event

The event that fired it.

## attempts

How many times it ran.

## lastError

The last failure.

## raw

The row as the server sent it.

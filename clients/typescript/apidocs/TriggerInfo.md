# TriggerInfo

A trigger, as a listing returns it.

## name

Its name.

## collection

Its collection.

## events

The writes it fires on.

## procedureName

The procedure it calls.

## timing

`after` or `before`.

## mode

`document` or `batch`.

## enabled

Whether it fires.

## version

Its version.

## definer

The user it runs as.

## raw

The row as the server sent it.

A geographic point, stored as `#geo(lat,lng)`.

@param lat latitude, -90 to 90
@param lng longitude, -180 to 180

## MAX_LATITUDE

The largest latitude, 90.

## MAX_LONGITUDE

The largest longitude, 180.

## of(double, double)

@param lat latitude, -90 to 90
@param lng longitude, -180 to 180
@return the point

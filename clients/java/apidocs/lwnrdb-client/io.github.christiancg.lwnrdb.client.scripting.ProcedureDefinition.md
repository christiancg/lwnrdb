A stored procedure to save. Built with `ProcedureDefinition.builder(name, script)`.

## builder(String, String)

@param name the procedure's name
@param script its SimpleJS source
@return a builder

## name()

@return the name

## script()

@return the source

## description()

@return the description

@return whether it is enabled, empty for the server's default
